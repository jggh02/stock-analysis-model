# MVO operates as Global Minimum Variance

When the user selects Mean-Variance Optimisation via the strategy enum, the optimizer uses equal expected returns for all tickers, reducing MVO to the Global Minimum Variance portfolio. This means MVO optimises purely on the covariance matrix, ignoring return forecasts — the same posture as HRP. We considered feeding historical mean returns (the textbook approach) or shrinkage estimates into MVO's expected-return vector, but rejected both: historical means are dominated by estimation error and produce unstable, concentrated weights ("MVO is an error maximiser"), and shrinkage adds complexity for marginal improvement. With the gate-then-tilt integration layer (ADR-0005) already handling return-based alpha via the forecaster, the base allocator doesn't need its own return estimates. Both HRP and MVO now serve as pure risk-based allocators, and return views enter only through the Tilt Factor.
